EMZLY — PREMIUM LUXURY HANDBAGS WEBSITE
Website owner / creator: Eman Fatima
Tagline: Carry Elegance. Define Your Style.

HOW TO RUN
1. Extract the EMZLY-WEBSITE.zip file.
2. Open the EMZLY-WEBSITE folder.
3. Double-click index.html to open the website in your browser.
4. For an optional local server, open a terminal in this folder and run: python -m http.server 8000
   Then visit http://localhost:8000.

PROJECT CONTENTS
- Eight pages: Home, About, Shop, Services, Contact, Blog, Login and Register.
- Bootstrap 5 CSS and JavaScript are stored locally in assets/css and assets/js.
- All page styling and interactions are stored locally.
- 15 distinct handbag product photos in 15 different colours, each carrying the EMZLY signature mark.
- The product logo uses a larger E with smaller MZLY lettering in a gold finish.
- Homepage includes an extended Colour Edit and brand-story section for a longer editorial browsing experience.
- Shopping cart and wishlist use browser localStorage for demo persistence.
- Product filtering, search, sorting and quick-view are available on the Shop page.

IMPORTANT DEMO NOTES
This is a static front-end website. Login, registration, checkout, payment and order processing are demonstrations only. A server-side backend and payment provider are required for real customer accounts and orders. Contact and newsletter forms show front-end confirmation only.

OFFLINE SUPPORT
Core pages, styles, scripts, Bootstrap and image assets are included locally. The site does not require a CDN or internet connection for its core layout and interactions.
